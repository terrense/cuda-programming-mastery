## 📚 理论基础

### YOLO模型架构

**YOLO (You Only Look Once)** 是一种实时目标检测算法，其特点是：
- **单阶段检测**: 直接预测边界框和类别概率
- **全卷积网络**: 适合GPU并行计算
- **多尺度特征**: 检测不同大小的目标

### YOLO网络结构分析

```
YOLO网络结构
├── Backbone (主干网络)
│   ├── CSPDarknet53/EfficientNet
│   ├── 卷积层 + 批归一化 + 激活
│   └── 残差连接
├── Neck (特征融合)
│   ├── FPN (特征金字塔网络)
│   ├── PAN (路径聚合网络)
│   └── 多尺度特征融合
└── Head (检测头)
    ├── 分类分支
    ├── 回归分支
    └── 置信度分支
```
